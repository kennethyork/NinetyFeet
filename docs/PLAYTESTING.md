# Playtesting Ninety Feet

## Test matrix

Record the build commit, OS/device, input method, display resolution and mode for every session.
Before a release, cover Windows keyboard/mouse and controller, Linux AppImage keyboard/controller,
and Android touch on both a phone and tablet when hardware is available.

## Twenty-minute first-session test

1. Start from a clean profile without coaching the player.
2. Ask them to begin the mode that interests them and narrate what they expect each control to do.
3. Have them bat, pitch, pause, change a setting and finish or leave a game.
4. Close the application completely, reopen it and verify that the same mode, club selections and
   progress resume.
5. Observe silently. Record hesitation, missed taps, unreadable text and incorrect expectations.

## Persistence regression

Exercise Exhibition, Season, Dynasty, Career, Collection, Moments and Online separately. Make a
distinctive selection or change in each, close the process without returning to the main menu, and
confirm every mode resumes its own state. For league modes, complete a trade and a game, then test
both the primary save and recovery from a deliberately damaged copy on a disposable profile.

## Gameplay and accessibility checks

- Complete plate appearances using touch, keyboard/mouse and controller.
- Verify pitch and swing feedback explains early/late timing and location.
- Navigate menus with no pointer and ensure Back never traps the player.
- Repeat with large text, high contrast, reduced motion and vibration disabled.
- Check 16:9, ultrawide and a narrow phone layout for clipped or untappable controls.
- Play every Moment twice and confirm the replay reward cannot repeat its first-clear pack.

## Feedback report

Ask for the three most confusing moments, the most satisfying play, whether the result felt fair,
and whether they would start another game. A useful bug includes build commit, platform/device,
input, mode, exact reproduction steps, expected result, actual result and a screenshot or video.
Do not include private IP addresses or copyrighted roster files in public reports.
