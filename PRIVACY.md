# Ninety Feet Privacy Notice

Last updated: August 6, 2026

Ninety Feet does not include advertising, analytics, telemetry, tracking SDKs or an account system.
The game does not send save files, rosters, settings or gameplay statistics to the developer.

Game progress and imported rosters are stored locally in Godot's application-data directory. On
Android, uninstalling the app or clearing its storage may delete that data.

Online play connects players directly using the network address they enter. A direct connection
necessarily exposes each player's IP address to the other participant and to the network providers
carrying the connection. Ninety Feet does not operate a matchmaking, relay or data-collection
server. Only connect to people you trust.

GitHub may process technical information when someone downloads a build or reports an issue on the
project repository under GitHub's own privacy terms. That processing is not controlled by the game.

Questions or privacy reports can be submitted through the project's GitHub issue tracker. If the
game later adds accounts, analytics, hosted multiplayer or other data collection, this notice must
be updated before that feature ships.
